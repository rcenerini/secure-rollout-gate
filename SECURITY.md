# Política de segurança

Este é um projeto pessoal de pesquisa, em fase de planejamento, sem versões publicadas.

## Como reportar uma vulnerabilidade

Use o recurso **Report a vulnerability** da aba Security do repositório (relato privado). Não abra uma issue pública com detalhes de exploração.

## Escopo

- Dentro do escopo: código, workflows e configuração deste repositório.
- Fora do escopo: ferramentas de terceiros citadas nos documentos (reporte aos mantenedores delas).

## Dados

Este repositório não deve conter segredos, dados reais nem código de terceiros. Se encontrar algo assim, avise pelo mesmo canal.
